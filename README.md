# 📋 Registre Annuel — Clinique Dentaire de Monastir

Application desktop développée spécifiquement pour la **Clinique de Médecine et de Chirurgie Dentaire de Monastir**, destinée à faciliter la gestion numérique du registre annuel des patients du **Service d'Odontologie Pédiatrique et de Prévention**.

## 🏥 Présentation

Cette application a été conçue spécifiquement pour répondre aux besoins du
**Service d'Odontologie Pédiatrique et de Prévention de la Clinique Dentaire de Monastir**.

Elle permet de remplacer la gestion traditionnelle du registre annuel par
une solution informatique simple, rapide et organisée.

L'application permet notamment de :

- 📅 gérer les registres par année ;
- 🗂️ attribuer automatiquement les numéros de dossier ;
- 👤 enregistrer le nom et le prénom des patients ;
- 📝 enregistrer le numéro de fiche ;
- 🔎 rechercher rapidement un patient ;
- ✏️ modifier directement les informations dans le registre ;
- 💾 sauvegarder les données dans une base de données SQLite locale.

- ## 🎯 Contexte du projet

Le projet a été réalisé afin de répondre à un besoin réel de gestion et
d'organisation des dossiers au sein du **Service d'Odontologie Pédiatrique
et de Prévention de la Clinique Dentaire de Monastir**.

L'objectif principal est de faciliter la consultation et la recherche des
informations enregistrées dans les registres annuels, tout en réduisant les
erreurs liées à la gestion manuelle des données.

L'application a été pensée pour être simple à utiliser par le personnel
du service, sans nécessiter de connaissances techniques particulières.

## Technologies utilisées

- **Python** — langage de programmation principal.
- **Tkinter** — création de l'interface graphique de l'application.
- **ttk (Themed Tkinter)** — personnalisation et gestion des composants de l'interface.
- **SQLite3** — gestion de la base de données locale.
- **PyInstaller** — création de l'application exécutable `.exe` pour Windows.
- **Git & GitHub** — gestion et hébergement du code source.
